# Schnellstart-Anleitung für das AI-Hub SDK

Diese Anleitung hilft Ihnen, mit dem AI-Hub SDK zu beginnen und behandelt die folgenden Themen:

- Einrichten Ihrer Entwicklungsumgebung
- Erstellen Ihres ersten Agenten
- Erstellen Ihrer ersten Pipeline

Ziel ist es, innerhalb von nur 30 Minuten einen funktionierenden Agenten und eine Pipeline in Ihrer Entwicklungsumgebung zu haben, auf denen Sie aufbauen können.

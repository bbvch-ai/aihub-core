# Compliance and regulations

The platform provides technical measures to support regulatory compliance. Organizations using the platform act as data
controllers and remain responsible for their own compliance.

## Coverage

This section documents the platform's compliance capabilities:

- **Data retention policies**: How the platform stores and expires data
- **GDPR compliance**: Support for EU data protection requirements
- **Swiss DSG**: Switzerland-specific data protection features
- **EU AI Act**: AI-specific regulatory considerations
- **Internationalization**: Multi-language support for Swiss organizations
- **Data subject access requests**: Handling data subject rights

## Data controller responsibility

The platform provides technical capabilities like audit logging, configurable retention, encryption, and access
controls. Organizations must configure these features appropriately for their regulatory requirements and use cases.

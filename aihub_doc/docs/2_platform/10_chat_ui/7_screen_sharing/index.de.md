# Bildschirmfreigabe

Wählen Sie „Mehr“ aus. ![„Mehr“ auswählen](../../../../media/open_webui/select_more_for_capture.jpeg)

Wählen Sie dann „Aufnehmen“ aus.

![„Aufnehmen“ auswählen](../../../../media/open_webui/select_capture_option.jpeg)

Wählen Sie aus, was aufgenommen werden soll: einen Browser-Tab, ein Fenster oder den gesamten Bildschirm.

![Aufnahmequelle auswählen](../../../../media/open_webui/choose_capture_source.jpeg)

Sobald die Auswahl getroffen ist, kann sie geteilt werden.

![Aufgenommenen Bildschirm teilen](../../../../media/open_webui/share_captured_screen.jpeg)

Das aufgenommene Bild erscheint im Chatfenster.

![Aufgenommenes Bild im Chat](../../../../media/open_webui/captured_image_in_chat.jpeg)

Geben Sie „Was können Sie mir über diesen Screenshot erzählen?“ ein.

Fragen Sie etwas zum Bild.

![Fragen zum Screenshot](../../../../media/open_webui/ask_about_screenshot.jpeg)

Und das Modell wird es analysieren und eine Antwort geben.

![Modell analysiert Screenshot](../../../../media/open_webui/model_analyzes_screenshot.jpeg)

Modelle, die keine visuellen Fähigkeiten unterstützen, geben eine Fehlermeldung aus.

![Fehler bei Vision-Modell](../../../../media/open_webui/vision_model_error.jpeg)

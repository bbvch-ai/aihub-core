# Screen Sharing

Select "More". ![Select More](../../../../media/open_webui/select_more_for_capture.jpeg)

Then select "Capture".

![Select Capture](../../../../media/open_webui/select_capture_option.jpeg)

Choose what should be captured, a tab from the browser, a window, or the entire screen.

![Choose Capture Source](../../../../media/open_webui/choose_capture_source.jpeg)

Once selected it can be shared.

![Share Captured Screen](../../../../media/open_webui/share_captured_screen.jpeg)

The captured image appears in the chat box.

![Captured Image in Chat](../../../../media/open_webui/captured_image_in_chat.jpeg)

Type "What can you tell me about this screenshot?"

Ask something about the image.

![Ask About Screenshot](../../../../media/open_webui/ask_about_screenshot.jpeg)

And the model will analyze it and give an answer.

![Model Analyzes Screenshot](../../../../media/open_webui/model_analyzes_screenshot.jpeg)

Models that don't support vision capabilities will produce an error.

![Vision Model Error](../../../../media/open_webui/vision_model_error.jpeg)

# Ihre ersten Einblicke

Die Schweizer AI-Hub Plattform bietet Zugang zu Agenten, die Fragen beantworten und Informationen abrufen können. Werfen
wir einen Blick darauf, welche Einblicke Sie durch die Interaktionen mit diesen Agenten gewinnen können.

## Nachvollziehbarkeit

Nachdem Sie eine Konversation mit einem Agenten begonnen haben, können Sie alle während der Interaktion generierten
Ereignisse überprüfen.

Der Tracing Service zeigt alle Interaktionen zwischen Agenten und Benutzern. Sie können jede Interaktion untersuchen, um
genau zu sehen, was der Agent getan und wie er die Antwort generiert hat. Sie können diese Ansicht auch direkt über die
Chat-Oberfläche öffnen, indem Sie das Tracing-Symbol unterhalb der Antwort des Agenten auswählen. Dies öffnet ein
Fenster von rechts mit derselben Ansicht wie die Service-Seite, sodass Sie eine Interaktion analysieren können, ohne den
Chat verlassen zu müssen.

## Dokumentenabruf

Sie können die Dokumententeile, die ein RAG Agent zur Beantwortung Ihrer Frage verwendet hat, direkt über die
Chat-Oberfläche einsehen. Dies ermöglicht es Ihnen, die Antwort des Agenten anhand des Dokumentinhalts zu überprüfen.

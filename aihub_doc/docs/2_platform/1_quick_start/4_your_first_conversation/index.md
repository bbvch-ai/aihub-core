# Your First Conversation

There are two ways to begin your first conversation with an agent inside the platform. One way is through the frontend
located under OpenAI in the services selection menu in the top left, this is the main way of communicating with agents.
Another way is through the agent itself, located under agents in the services selection menu. Both ways are possible but
the frontend is the main intended way for most users.

## Frontend

As a frontend we use [Open WebUI](https://github.com/open-webui/open-webui) an open source web interface. To begin your
first conversation after logging in with azure, just start typing your message and then hit enter. To switch to a
different model or an agent you can select them in the top left of the chat and even set one as your default. Here it is
also possible to set up a temporary chat by selecting the toggle at the bottom. Now you are all set, use the chat as you
would any other. A more detailed overview of all features in the chat can be found
[here](../../5_feature_overview/chat_interface/).

## Agent

In the agent overview select the agent you want to chat with and then select the Chat tab at the top of the new window.
Here you can enter a message and begin talking to the agent. Once having started your conversation you will be able to
see the whole trace of what the agent is doing.

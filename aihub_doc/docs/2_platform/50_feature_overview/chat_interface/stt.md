## Speech To Text

Begin a voice recording.

[![](./images/user/img_64126fa34f.jpeg)](../public/images/user/img_64126fa34f.jpeg)

A timeline indicates how long the recording has lasted.

[![](./images/user/img_14e5f79210.jpeg)](../public/images/user/img_14e5f79210.jpeg)

To complete the recording and transcribe the audio as a prompt select the check mark.

[![](./images/user/img_8251d01d87.jpeg)](../public/images/user/img_8251d01d87.jpeg)

The recorded audio will be displayed as input which can be altered or directly sent to the model.

[![](./images/user/img_be9ec6f4c3.jpeg)](../public/images/user/img_be9ec6f4c3.jpeg)

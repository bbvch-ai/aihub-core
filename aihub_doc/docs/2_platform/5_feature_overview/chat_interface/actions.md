## Actions

Actions are the small icons underneath each response from the model. These can perform different things, from reading
the response aloud to giving feedback on the quality of the answer.

The response can be edited.

[![](../../../../media/feature_overview/chat_interface/user/actions_edit.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_edit.jpeg)

Copy the response to clipboard.

[![](../../../../media/feature_overview/chat_interface/user/actions_copy.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_copy.jpeg)

Read the response aloud.

[![](../../../../media/feature_overview/chat_interface/user/actions_tts.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_tts.jpeg)

Generate an image based on the response.

[![](../../../../media/feature_overview/chat_interface/user/actions_image_gen.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_image_gen.jpeg)

Positive feedback can be given.

[![](../../../../media/feature_overview/chat_interface/user/actions_feedback_pos.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_feedback_pos.jpegg)

Here the response can be rated and enriched with details in order to better evaluate how well the models perform.

[![](../../../../media/feature_overview/chat_interface/user/actions_feedback_rating.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_feedback_rating.jpeg)

Negative feedback can also be given.

[![](../../../../media/feature_overview/chat_interface/user/actions_feedback_neg.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_feedback_neg.jpeg)

The response can be continued.

[![](../../../../media/feature_overview/chat_interface/user/actions_continue.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_continue.jpeg)

The response can be regenerated.

[![](../../../../media/feature_overview/chat_interface/user/actions_regenerate.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_regenerate.jpeg)

Regenerated responses can be deleted again.

[![](../../../../media/feature_overview/chat_interface/user/actions_delete.jpeg)](../../../../media/feature_overview/chat_interface/user/actions_delete.jpeg)

## Web Search

Select "Web Search".

[![](./images/user/img_8dcd927462.jpeg)](../public/images/user/img_8dcd927462.jpeg)

Enter something you want to search for.

[![](./images/user/img_0bddb5f76c.jpeg)](../public/images/user/img_0bddb5f76c.jpeg)

The model will take some time coming up with a search query and then executing that search. After which it will output
what it found.

[![](./images/user/img_e322b623d1.jpeg)](../public/images/user/img_e322b623d1.jpeg)

The websites it retrieved the information from are listed as references.

[![](./images/user/img_e2b502fcfb.jpeg)](../public/images/user/img_e2b502fcfb.jpeg)

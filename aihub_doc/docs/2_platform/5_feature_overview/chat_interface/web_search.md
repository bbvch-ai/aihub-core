## Web Search

Select "Web Search".

[![](../../../../media/feature_overview/chat_interface/user/web_search_button.jpeg)](../../../../media/feature_overview/chat_interface/user/web_search_button.jpeg)

Enter something you want to search for.

[![](../../../../media/feature_overview/chat_interface/user/web_search_message.jpeg)](../../../../media/feature_overview/chat_interface/user/web_search_message.jpeg)

The model will take some time coming up with a search query and then executing that search. After which it will output
what it found.

[![](../../../../media/feature_overview/chat_interface/user/web_search_output.jpeg)](../../../../media/feature_overview/chat_interface/user/web_search_output.jpeg)

The websites it retrieved the information from are listed as references.

[![](../../../../media/feature_overview/chat_interface/user/web_search_references.jpeg)](../../../../media/feature_overview/chat_interface/user/web_search_references.jpeg)

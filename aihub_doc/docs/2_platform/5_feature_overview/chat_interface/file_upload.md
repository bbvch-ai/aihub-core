## File Upload

To upload files click the "More" button.

[![](./images/user/img_e183e81bf2.jpeg)](../public/images/user/img_e183e81bf2.jpeg)

Then select "Upload Files". In the pop up navigate to the files you want to use and upload them.

[![](./images/user/img_af52ff5696.jpeg)](../public/images/user/img_af52ff5696.jpeg)

After uploading the files write ask a question.

[![](./images/user/img_8351d75f1f.jpeg)](../public/images/user/img_8351d75f1f.jpeg)

The model will use the files to answer the question.

[![](./images/user/img_4f8de2d345.jpeg)](../public/images/user/img_4f8de2d345.jpeg)

Click on a reference to view which parts where used to answer the question.

[![](./images/user/img_e53c46f2a9.jpeg)](../public/images/user/img_e53c46f2a9.jpeg)

The citation gives a clear rundown of the different parts used to generate the answer.

[![](./images/user/img_f611a23ef6.jpeg)](../public/images/user/img_f611a23ef6.jpeg)

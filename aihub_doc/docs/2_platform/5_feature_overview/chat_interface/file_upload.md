## File Upload

To upload files click the "More" button.

[![](../../../../media/feature_overview/chat_interface/user/file_upload_more_options.jpeg)](../../../../media/feature_overview/chat_interface/user/file_upload_more_options.jpeg)

Then select "Upload Files". In the pop up navigate to the files you want to use and upload them.

[![](../../../../media/feature_overview/chat_interface/user/file_upload_button.jpeg)](../../../../media/feature_overview/chat_interface/user/file_upload_button.jpeg)

After uploading the files write ask a question.

[![](../../../../media/feature_overview/chat_interface/user/upload_file_input_text.jpeg)](../../../../media/feature_overview/chat_interface/user/upload_file_input_text.jpeg)

The model will use the files to answer the question.

[![](../../../../media/feature_overview/chat_interface/user/file_upload_output.jpeg)](../../../../media/feature_overview/chat_interface/user/file_upload_output.jpeg)

Click on a reference to view which parts where used to answer the question.

[![](../../../../media/feature_overview/chat_interface/user/file_upload_show_source.jpeg)](../../../../media/feature_overview/chat_interface/user/file_upload_show_source.jpeg)

The citation gives a clear rundown of the different parts used to generate the answer.

[![](../../../../media/feature_overview/chat_interface/user/file_upload_source.jpeg)](../../../../media/feature_overview/chat_interface/user/file_upload_source.jpeg)

# OpenCode Event Type Mapping to Swiss AI-Hub Protocol

**Purpose**: Complete reference for converting OpenCode AssistantMessage parts to Swiss AI-Hub events.

**Context**: AgentDeveloperAgent proxies between OpenWebUI (Swiss AI-Hub) and OpenCode Server. OpenCode returns AssistantMessage objects containing various Part types that need conversion to Swiss AI-Hub protocol events.

---

## OpenCode Part Types (Complete List)

OpenCode SDK defines 7 part types in the `Part` union:

```python
Part: TypeAlias = Annotated[
    Union[TextPart, FilePart, ToolPart, StepStartPart, StepFinishPart, SnapshotPart, PatchPart],
    PropertyInfo(discriminator="type"),
]
```

**Note**: PatchPart is mentioned in the union but not implemented in SDK v0.1.0a36.

---

## Swiss AI-Hub Event Types (Available)

### Display Events (User-facing)
- **ChunkEvent**: Streaming text content to user
- **ThoughtEvent**: Internal reasoning/planning (not final output)
- **DisplayEvent**: Base class for user-visible events

### Control Events (Workflow)
- **ExceptionEvent**: Errors during execution
- **StopEvent**: Workflow completion
- **StartEvent**: Workflow initiation

### Semantic Events (Observability)
- **ToolEvent**: Tool execution tracking
- **LLMEvent**: LLM call tracking
- **LLMStopEvent**: LLM completion

### Cost Events (Billing/Usage)
- **CostEvent**: Generic cost tracking
- **LLMCostEvent**: LLM-specific cost/token usage

## Event Type Mapping (Detailed)

### 1. TextPart → ChunkEvent

**OpenCode Structure**:
```python
class TextPart(BaseModel):
    text: str
    id: str
    message_id: str
    session_id: str
    type: Literal["text"]
    synthetic: bool | None  # Generated by system vs user
    time: float | None      # Timestamp
```

**Current Handling**: ✅ **Implemented**
```python
if part.type == "text":
    events.append(ChunkEvent(content=part.text))
```

**Recommendation**: **Keep as-is**

**Rationale**:
- TextPart represents AI's primary textual response
- ChunkEvent is the perfect match for streaming text to user
- Simple, clean, no additional metadata needed

**Example Output**:
```
I'll create a RAG agent for you with the following structure...
```

### 2. FilePart → ChunkEvent (Formatted)

**OpenCode Structure**:
```python
class FilePart(BaseModel):
    id: str
    message_id: str
    mime: str
    session_id: str
    type: Literal["file"]
    url: str
    filename: str | None
    source: FileSource | None  # Contains path, text content, etc.
```

**Current Handling**: ✅ **Implemented**
```python
elif part.type == "file" and show_file_changes:
    file_event = format_opencode_file_change(part, verbose_output)
    if file_event:
        events.append(file_event)

def format_opencode_file_change(file_part, verbose_output):
    path = file_part.source.path if hasattr(file_part, "source") else "unknown"
    action = "📝 Modified" if getattr(file_part, "modified", False) else "✅ Created"
    content = f"{action}: `{path}`\n"
    if verbose_output and hasattr(file_part, "source") and hasattr(file_part.source, "text"):
        preview = file_part.source.text[:200]
        content += f"```python\n{preview}...\n```\n"
    return ChunkEvent(content=content)
```

**Recommendation**: **Consider adding ToolEvent for observability**

**Rationale**:
- Current implementation is good for user display
- Could also emit ToolEvent for observability/tracing
- Allows Phoenix to track file operations separately

**Enhanced Implementation**:
```python
# For user display
events.append(ChunkEvent(content=f"✅ Created: `{path}`\n"))

# For observability (optional)
events.append(ToolEvent(
    name="file_write",
    input={"path": path, "operation": "create"},
    output={"success": True},
))
```

**Example Output**:
```
✅ Created: `/workspace/agent/LegalRAGAgent.py`
```

### 3. ToolPart → ChunkEvent + ToolEvent

**OpenCode Structure**:
```python
class ToolPart(BaseModel):
    id: str
    call_id: str
    message_id: str
    session_id: str
    state: State  # Union of Pending/Running/Completed/Error
    tool: str      # Tool name (e.g., "pytest", "bash")
    type: Literal["tool"]

# State is discriminated union:
State = Union[ToolStatePending, ToolStateRunning, ToolStateCompleted, ToolStateError]
```

**State Variants**:

#### 3a. ToolStatePending
```python
class ToolStatePending(BaseModel):
    status: Literal["pending"]
```

**Current Handling**: ⚠️ **Partial** (treated as generic "Executing")
```python
else:  # Not completed, error, or running
    emoji = "🔧"
    status = "Executing"
```

**Recommendation**: **Add specific pending handler**
```python
elif state.status == "pending":
    emoji = "⏸️"
    status = "Queued"
    content = f"{emoji} **{status}:** `{tool_name}`\n"
```

**Rationale**:
- Pending indicates tool is queued but not started
- Different UX than "running" (which is actively executing)
- Helps user understand why delay might occur

**Example Output**:
```
⏸️ **Queued:** `pytest`
```

#### 3b. ToolStateRunning
```python
class ToolStateRunning(BaseModel):
    status: Literal["running"]
    time: Time  # start: float
    input: object | None
    metadata: dict | None
    title: str | None
```

**Current Handling**: ✅ **Implemented**
```python
elif state == "running":
    emoji = "⏳"
    status = "Running"
```

**Recommendation**: **Enhance with elapsed time (optional)**

**Rationale**:

- Useful for long-running operations (tests, builds)

**Example Output**:

**Current Handling**: ❌ **Not handled** (ignored completely)

**Recommendation**: **Emit LLMCostEvent for cost tracking**
```python
elif part.type == "step-finish":
    # Emit cost event for billing/observability
    events.append(LLMCostEvent(
        total_cost=part.cost,
        input_tokens=int(part.tokens.input),
        output_tokens=int(part.tokens.output),
        reasoning_tokens=int(part.tokens.reasoning),
```

**Rationale**:
- **Critical for cost tracking** - Swiss AI-Hub uses LLMCostEvent for billing

## Implementation Example (Complete)

```python
def convert_opencode_response_to_events(
    response: Any,
    show_file_changes: bool = True,
    show_tool_calls: bool = True,
    verbose_output: bool = False,
) -> list[ChunkEvent | ToolEvent | LLMCostEvent | ThoughtEvent]:
    """Convert OpenCode AssistantMessage parts to Swiss AI-Hub events."""
    events: list[ChunkEvent | ToolEvent | LLMCostEvent | ThoughtEvent] = []

    for part in response.parts:
        # 1. TextPart → ChunkEvent
        if part.type == "text":
            events.append(ChunkEvent(content=part.text))

        # 2. FilePart → ChunkEvent + ToolEvent
        elif part.type == "file" and show_file_changes:
            path = part.source.path if hasattr(part, "source") else "unknown"
            action = "📝 Modified" if getattr(part, "modified", False) else "✅ Created"
            events.append(ChunkEvent(content=f"{action}: `{path}`\n"))

            # Observability
            events.append(ToolEvent(
                name="file_write",
                input={"path": path},
                output={"success": True},
            ))

        # 3. ToolPart → ChunkEvent + ToolEvent
        elif part.type == "tool" and show_tool_calls:
            tool_name = part.tool
            state = part.state

            # 3a. Pending
            if state.status == "pending":
                events.append(ChunkEvent(content=f"⏸️ **Queued:** `{tool_name}`\n"))

            # 3b. Running
            elif state.status == "running":
                elapsed = time.time() - state.time.start if state.time else 0
                if elapsed > 3:  # Only show if > 3s
                    events.append(ChunkEvent(content=f"⏳ **Running ({elapsed:.1f}s):** `{tool_name}`\n"))
                else:
                    events.append(ChunkEvent(content=f"⏳ **Running:** `{tool_name}`\n"))

            # 3c. Completed
            elif state.status == "completed":
                events.append(ChunkEvent(content=f"✅ **Completed:** `{state.title}`\n"))

                # Observability
                events.append(ToolEvent(
                    name=tool_name,
                    input=state.input,
                    output=state.output,
                    metadata={
                        "duration": state.time.end - state.time.start,
                        **state.metadata,
                    }
                ))

            # 3d. Error
            elif state.status == "error":
                events.append(ChunkEvent(content=f"❌ **Failed:** `{tool_name}`\n\n```\n{state.error[:500]}\n```\n"))

                # Observability
                events.append(ToolEvent(
                    name=tool_name,
                    input=state.input,
                    output=None,
                    metadata={
                        "error": state.error,
                        "duration": state.time.end - state.time.start,
                    }
                ))

        # 4. StepStartPart → ThoughtEvent
        elif part.type == "step-start":
            events.append(ThoughtEvent(content="🧠 **Thinking...**\n"))

        # 5. StepFinishPart → LLMCostEvent + ThoughtEvent
        elif part.type == "step-finish":
            # Cost tracking (always emit)
            events.append(LLMCostEvent(
                total_cost=part.cost,
                input_tokens=int(part.tokens.input),
                output_tokens=int(part.tokens.output),
                reasoning_tokens=int(part.tokens.reasoning),
                cache_read_tokens=int(part.tokens.cache.read),
                cache_write_tokens=int(part.tokens.cache.write),
                model_id="unknown",
            ))

            # User display (verbose only)
            if verbose_output:
                total_tokens = int(
                    part.tokens.input +
                    part.tokens.output +
                    part.tokens.reasoning
                )
                events.append(ThoughtEvent(
                    content=f"💰 **Cost:** ${part.cost:.4f} ({total_tokens} tokens)\n"
                ))

        # 6. SnapshotPart → Skip (or verbose)
        elif part.type == "snapshot":
            if verbose_output:
                events.append(ChunkEvent(content=f"📸 **Snapshot:** {part.snapshot}\n"))

        # 7. PatchPart → Future-proofing
        elif part.type == "patch":
            if show_file_changes:
                events.append(ChunkEvent(content="🔧 **Patch applied**\n"))

    return events
```

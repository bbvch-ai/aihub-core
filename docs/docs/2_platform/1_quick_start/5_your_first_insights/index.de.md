# Ihre ersten Einblicke

Die Swiss AI Hub Plattform bietet Zugriff auf Agents, die Fragen beantworten und Informationen abrufen können. Lassen
Sie uns untersuchen, welche Einblicke Sie aus Interaktionen mit diesen Agents gewinnen können.

## Nachvollziehbarkeit

Nachdem Sie eine Konversation mit einem beliebigen Agenten gestartet haben, können Sie alle während der Interaktion
generierten Ereignisse überprüfen.

Der Tracing-Service zeigt alle Interaktionen zwischen Agents und Benutzern an. Sie können jede Interaktion untersuchen,
um genau zu sehen, was der Agent getan hat und wie er die Antwort generiert hat. Sie können diese Ansicht auch direkt
über die Chat-Oberfläche öffnen, indem Sie das Tracing-Symbol unterhalb der Antwort des Agenten auswählen. Dies öffnet
ein Fenster von rechts mit derselben Ansicht wie die Service-Seite, wodurch Sie eine Interaktion analysieren können,
ohne den Chat verlassen zu müssen.

## Dokumentenabruf

Sie können die Dokumententeile, die ein RAG-Agent zur Beantwortung Ihrer Frage verwendet hat, direkt über die
Chat-Oberfläche einsehen. Dies ermöglicht es Ihnen, die Antwort des Agenten anhand der Dokumenteninhalte zu überprüfen.

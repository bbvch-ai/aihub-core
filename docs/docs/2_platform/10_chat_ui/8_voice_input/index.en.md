---
title: Voice Input
---

Begin a voice recording.

![Begin Voice Recording](../../../../media/open_webui/begin_voice_recording.jpeg)

A timeline indicates how long the recording has lasted.

![Recording Timeline](../../../../media/open_webui/recording_timeline.jpeg)

To complete the recording and transcribe the audio as a prompt select the check mark.

![Complete Recording](../../../../media/open_webui/complete_recording_checkmark.jpeg)

The recorded audio will be displayed as input which can be altered or directly sent to the model.

![Transcribed Audio Input](../../../../media/open_webui/transcribed_audio_input.jpeg)

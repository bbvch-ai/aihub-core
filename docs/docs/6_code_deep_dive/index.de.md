# Code Deep Dive

:::info Automatisch generierter Inhalt
Dieser Abschnitt wird automatisch aus den README.md-Dateien im Quellcode-Repository generiert. Der Inhalt wird während
des Dokumentations-Build-Prozesses synchronisiert und spiegelt den aktuellen Stand der Codebasis wider.
:::

Dieser Abschnitt bietet einen tiefen Einblick in die Swiss AI Hub-Codebasis, einschließlich:

- **Introduction**: Übersicht aus dem Root-README
- **Package-Dokumentation**: Detaillierte README-Dateien aus jedem Package
- **Changelog**: Vollständige Änderungshistorie
- **Licenses**: Software-Lizenzen und Zuschreibungen
